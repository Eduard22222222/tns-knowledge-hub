# Niche Society — Aesthetic

Child vault of [[The Niche Society Vault/README|The Niche Society]].
White-label SaaS template for **aesthetic / cosmetic medicine clinics** in Romania (botox, filler, laser, body contouring, PRP, HydraFacial, etc.).

## Why aesthetic first
- Highest average ticket (€200–€1500/treatment)
- Youngest userbase (25–45), app-native
- Photo-driven loop built in (before/after)
- Referrals already cultural
- Clinics spend 20–40% of revenue on marketing — easy sell

## Tech stack (planned)
- Next.js 15 (web apps) + React Native (mobile patient app)
- Supabase EU (Frankfurt) — auth, db, storage, realtime
- Tailwind + Radix + React Bits components
- Framer Motion for micro-interactions
- Claude Sonnet 4.6 for AI features
- Stripe for subscriptions + MLM payouts
- Resend for transactional email, Vonage/Twilio for SMS/WhatsApp
