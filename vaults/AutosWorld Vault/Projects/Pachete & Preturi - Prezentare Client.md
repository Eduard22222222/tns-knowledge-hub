# Pachete & Prețuri — Prezentare pentru Client

> Document **comunicabil clientului**. Traduce cele 4 variante tehnice (A/B/C/D din [[Variante Build & Plugin-uri - Pros-Cons Detaliat]]) în **3 pachete pe limba clientului**, cu preț. Format good/better/best (ca proposal-urile TNS).

## Mesajul de bază (cum deschizi)
> „Toate variantele înseamnă **design custom făcut de noi — NU un template generic** ca la toată lumea. Diferența e **cum e construit în spate**: cât de mult poți umbla singur în site, cât de rapid și sigur e, și prețul. Îți dau 3 variante și-ți spun pe care o recomand."

---

## Analogia (ca să înțeleagă clientul instant)
- **Template generic** = apartament mobilat standard, ca toate celelalte. ❌ Asta NU facem.
- **Pachet START (builder)** = mobilier modular premium pe care **tu îl rearanjezi** oricând. Flexibil, dar mai multe piese de întreținut.
- **Pachet STANDARD (temă custom)** = amenajare făcută de **arhitect pe gustul tău**. Pe măsură; schimbările mari le face arhitectul, dar tu schimbi singur tablourile/textele.
- **Pachet PREMIUM (headless)** = casă **proiectată de la zero**, cele mai bune materiale, cea mai rapidă și sigură. Vârf de gamă, cost pe măsură.

---

## 🟢 Pachet START — „Builder" (varianta C)
**Ce înseamnă:** site cu design custom construit pe un page builder (Bricks). **Tu poți edita singur orice** — muți secțiuni, schimbi imagini, adaugi pagini, fără programator.

| | |
|---|---|
| **Design** | Custom (nu template), construit vizual |
| **Cât umbli singur** | ✅ Tot — autonomie maximă |
| **Viteză site** | Bună (puțin mai grea decât custom) |
| **Securitate** | Bună, dar +1 componentă de întreținut |
| **Timp livrare** | Cel mai rapid |
| **Preț build** | **~3.000–3.500 EUR** |

**Bun pentru tine dacă:** vrei să umbli singur în site permanent, buget mai mic, lansare rapidă.
**Compromis onest:** componenta de „builder" e o piesă în plus de securizat/actualizat; magazinul e ușor mai greu.

---

## 🔵 Pachet STANDARD — „Custom pe măsură" (varianta B/FSE) ⭐ RECOMANDAT
**Ce înseamnă:** îți construim o **temă proprie, de la zero**, pe identitatea ta — design exact cum îl vrem, rapid și sigur. Tu poți edita singur **conținutul** (texte, bannere, produse, pagini); la modificări mari de design intervenim noi.

| | |
|---|---|
| **Design** | 100% custom, nativ, lean |
| **Cât umbli singur** | ✅ Conținut (texte/produse/bannere) |
| **Viteză site** | Foarte bună |
| **Securitate** | Foarte bună (puține componente = suprafață mică) |
| **Timp livrare** | Mediu |
| **Preț build** | **4.000 EUR** (bugetul deja stabilit) |

**Bun pentru tine dacă:** vrei un magazin care arată ca al tău (nu ca al altora), rapid și sigur, fără să plătești premium. **Aici se încadrează fix bugetul nostru.**

---

## 🟣 Pachet PREMIUM — „Vitrină proprie / Headless" (varianta D)
**Ce înseamnă:** partea pe care o văd clienții (vitrina) e construită **complet separat**, cu cea mai modernă tehnologie (ca site-urile marilor branduri) — **cel mai rapid și cel mai sigur posibil**, design fără nicio limită. WordPress rămâne doar „în spate", pentru administrare și plugin-uri (facturare, plăți, AWB).

| | |
|---|---|
| **Design** | Fără limite, premium, animații |
| **Cât umbli singur** | Conținut din admin |
| **Viteză site** | Vârf (cele mai bune scoruri) |
| **Securitate** | Cea mai bună (vitrina nu expune deloc WordPress) |
| **Timp livrare** | Cel mai lung |
| **Preț build** | **~6.500–8.500 EUR** (peste bugetul actual) |

**Bun pentru tine dacă:** vrei un brand care iese în evidență, performanță maximă, și ai buget peste cei 4.000.

## 💰 Trebuie modificat pricing-ul? — răspuns onest
**Build-ul NU se modifică pt varianta recomandată: STANDARD = 4.000 EUR**, exact cât am stabilit. ✅
Ce trebuie **completat** (nu mărit) e partea recurentă — altfel oferta e incompletă și pică pe noi:

### A) Abonamente lunare (le plătește clientul direct)
| Serviciu | Cost aprox. |
|---|---|
| Hosting managed | €15–40 / lună |
| Soft facturare (Oblio/SmartBill) | ~€10–20 / lună |
| EasySales (**doar dacă vinde pe eMAG**) | ~€20–50 / lună |
| Netopia | fără abonament, ~1% / tranzacție |
| Plugin-uri premium (cache/securitate) | ~€100–200 / an |
| **Total run** | **~€50–120 / lună** |

### B) Retainer mentenanță & securitate (venit TNS)
| | |
|---|---|
| Ce include | update-uri, backups, monitorizare securitate, patching la timp, mici fix-uri |
| Preț | **~€100–150 / lună** (sau pachet trimestrial) |
| De ce | fără el, NU garantăm site-ul în timp (vezi [[Vulnerabilitati Reale + Cum le Batem]]) — un magazin cu plăți + date personale nemenținut = răspundere |

> **Concluzie pricing:** 4.000 EUR (build) **rămâne**. Adăugăm transparent: **~€150–270/lună total** (abonamente + retainer) ca să funcționeze corect. Asta protejează și clientul, și noi — și e și **venit recurent** pentru TNS.
