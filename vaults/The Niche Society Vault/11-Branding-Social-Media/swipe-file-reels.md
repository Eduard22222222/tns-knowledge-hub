# Swipe File — Reels AI (inspirație)

> Cele mai virale/utile reels AI văzute în scroll. Append dated. Feed-ul contului @onlythenichesociety s-a încălzit (majoritatea organice = AI). Vezi factorii recurenti in [[virality-playbook]].

## 2026-08-27 (primul scroll manual, contul cald)

### @nick_saraev — "Comment PLUGIN to get these 5 Free Claude Code Plugins" ⭐ TOP
- Metrici (vizibile): **34.5K likes · 28.1K COMENTARII · 1.084 shares**
- Hook: număr + gratis + tool ("5 Free Claude Code Plugins")
- Format: talking-head / screen-record, resource-giveaway
- **De ce prinde:** comment-keyword-to-DM. Raport comentarii/likes ENORM (28K/34K) — keyword-ul („PLUGIN") forțează comentarii, care umflă reach-ul. Ăsta e cel mai puternic mecanism văzut.
- **Cum adaptăm:** exact ce facem deja ("Comment REPOS/HARNESS/REAL"). De dublat: oferă o resursă concretă gratis în schimbul comentariului (listă de repos, cheat-sheet).

### @felixbravoai — "These 5 websites completely changed how I build with AI 🚀"
- Metrici: 13.8K likes · 1.604 comentarii · 122 shares
- Hook: listicle + transformare personală ("changed how I build")
- Format: listicle de tool-uri/site-uri (screen-record probabil)
- **De ce prinde:** listicle = saveable; "changed how I" = curiozitate + relatabilitate; tool-uri concrete.
- **Cum adaptăm:** avem deja "6 repos" / "5 tools" — adăugăm unghi personal ("cum livrăm noi 2x mai repede cu astea").

### @olli.rasmussen — "THIS is the #1 sidehustle in 2026" (#claudeai, tierlist)
- Metrici: 482 likes · 103 comentarii · 12 shares (cont mai mic/mai nou)
- Hook: superlativ + an ("THIS is the #1 ... in 2026")
- Format: tier-list
- **De ce prinde:** superlativ + curiozitate + monetizare (sidehustle). Tier-list = format ușor de urmărit.
- **Cum adaptăm:** un tier-list "AI tools ranked" sau "AI sidehustles" (encadrat onest).

### Pattern-uri confirmate azi
1. **Comment-keyword-to-DM = mecanismul #1** (comentariile > likes → reach). Oferă mereu o resursă gratis în schimb.
2. Listicle + transformare ("5 X that changed how I...") = saveable + curiozitate.
3. Superlativ/curiozitate ("THIS is the #1...", "nobody's talking about").
4. Toate: caption cu primă linie-hook + text pe ecran (mulți se uită pe mut).
5. Creatori de urmărit/analizat: @nick_saraev, @felixbravoai, @olli.rasmussen (pe langă cei deja urmariti).

### 3 idei de reel pt TNS (din ce am văzut)
1. **"Comment REPOS for 6 AI repos that feel illegal"** — refolosim reel-ul repos + CTA giveaway agresiv (listă reală în DM). (mecanismul lui nick_saraev)
2. **"5 AI tools that changed how we deliver client work"** — listicle personal cu screenshot-uri reale (unghiul felixbravo).
3. **"AI tools ranked: S / A / B tier"** — tier-list vizual (formatul olli.rasmussen), cu tool-urile din research-ul zilnic.
