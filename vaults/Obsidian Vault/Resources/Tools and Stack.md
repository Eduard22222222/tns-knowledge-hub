# Tools and Stack

## Development
- **Claude Code** - Primary development tool (builds everything)
- **VS Code** - Editor
- **Git** - Version control

## AI Generation
- **[[Higgsfield]] Cinema** - Character + video generation (reels)
- **[[Nanobanana]] / Gemini** - Image/background generation
- **Stability AI** - Image generation alternative

## Design & Documents
- **Canva** (MCP integrated) - Design, presentations
- **DaVinci Resolve** - Video editing
- **Remotion** - Programmatic video editing

## Proposal Pipeline
- Python scripts (`build_proposal.py`, `build_carousel*.py`) for generating PDFs
- Multiple iteration workflow (v1 -> vN -> FINAL)

## APIs & Services
- **Postman** (MCP integrated) - API testing
- **Supabase** (MCP integrated) - Backend/database
- **Ahrefs** (MCP integrated) - SEO analysis
- **SmartBill API** - Romanian invoicing (Salt Bank project)

## Hosting
- **RunPod EU** - GPU hosting for AI models (Salt Bank)
- **Vercel** - Web deployment
