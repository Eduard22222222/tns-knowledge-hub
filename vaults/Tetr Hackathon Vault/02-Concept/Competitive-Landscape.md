# Competitive Landscape — and why we still win

Yes there are alternatives. Every good hackathon idea has them. The question isn't "is the space empty" — it's "is there a *specific angle* nobody's taken well". Here's the honest map.

## Existing tools (scanned)

| Tool | Vertical | Format | Price | Gap they leave |
|------|----------|--------|-------|----------------|
| **Yoodli** (YC) | Interview/speaking | Video analysis, metrics | Freemium, ~$30/mo | No game mechanic, no story, corporate-feeling |
| **Google Interview Warmup** | Interview | Free Q&A with feedback | Free | Single vertical, no stakes, no progression |
| **Poised** | Meetings | Real-time coach overlay | ~$15/mo | Live-only, no practice mode |
| **Rizz app** | Dating | AI reply generator | $10/mo | *Writes for you* — doesn't teach, no scoring |
| **Wing** | Dating | AI flirt coach | Freemium | Same as Rizz — assistive, not educational |
| **Second Nature / Hyperbound** | Sales | Roleplay training for teams | B2B, $$$ | Enterprise only, boring UI, no game |
| **Exec** (YC) | Executive coaching | AI roleplay | ~$30/mo | Serious-professional, not for masses |
| **Character.ai** | Generic roleplay | Open chat with AI chars | Free | No scoring, no coaching, no structure |
| **Duolingo** | Language | Gamified drills | Freemium | Different domain but the mechanic model everyone copies |

## What nobody has built

**A single game that covers every high-stakes conversation in a person's life, with gamey progression, visual-novel aesthetic, a cheap one-time price, and a shareable score.**

Every existing player is one of:
- **Single-vertical tool** (Yoodli, Rizz) → we span 6 modes
- **Enterprise sales training** (Second Nature) → we're consumer & cheap
- **Assistive writer** (Rizz, Hyperwrite) → we teach, don't write for you
- **Generic roleplay** (Character.ai) → we score + coach + progress
- **Coaching subscription** ($30/mo) → we're €4.99 one-time

## Why this matters for a 48h hackathon specifically

Judges aren't looking for "a defensible startup moat" — they're looking for:
1. **Problem clarity** (we have it — everyone has hard convos coming up)
2. **Product thinking** (visual novel + tactic buttons + stars)
3. **Simulation depth** (counterfactual alt-lines are unique)
4. **Creativity** (the multi-mode + visual-novel combo nobody has)
5. **Business impact** (measurable learning + real revenue)

We don't need to beat Yoodli. We need a creative, demonstrably better prototype in a specific lane, shipped in 48h, with 100 users and $100 revenue. That's a completely different bar.

## What would make me pivot

If Eduard is genuinely worried about differentiation, the only real concern is: **is the Date Mode novel enough that it'll carry the virality**? My answer: yes — Rizz writes for you, we *coach* you. Very different product. Rizz has 1M+ downloads; even 0.1% of that appetite is 1000 users for us.

Pick one and we lock.

## Bottom line

There are tools in adjacent spaces. There is **no tool that does what we're building**. In 48h, we need to ship ONE thing people share. We have it. The only failure mode is scope creep — stop researching, start building.
