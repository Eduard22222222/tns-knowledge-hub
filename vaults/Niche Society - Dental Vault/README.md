# Niche Society — Dental

Child vault of [[The Niche Society Vault/README|The Niche Society]].
White-label SaaS template for **dental clinics** in Romania (general dentistry, orthodontics, implantology, endodontics, pediatric dental).

## Why dental is its own template
- Treatment plans span months/years (orthodontics, implants)
- Visual tooth chart is THE central UI — nothing like it in derm/aesthetic
- Financing / payment plans more common (treatment cost €1k–€15k)
- Radiography (X-ray, CBCT) viewer required
- Family accounts common (parents manage kids)

## Planned dental-specific features
- **Interactive tooth chart (FDI notation 11–48)** — clickable, color-coded per status (healthy/cavity/filled/crown/missing/planned)
- Treatment plan timeline with cost breakdown
- X-ray / photo viewer with annotations
- Financing calculator (monthly plan vs lump sum)
- Orthodontic progress tracker (aligners, bracket photos)
- Family account linking
- Recall reminders (6-month cleaning)
