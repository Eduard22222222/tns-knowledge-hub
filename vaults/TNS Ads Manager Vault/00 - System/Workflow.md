# Workflow — Onboarding client nou

## Faza 0: Discovery (zi 1)
- [ ] Completare brief client (template din `02 - Templates/Client Brief Template.md`)
- [ ] Audit site: viteză, mobile, tracking existent
- [ ] Verificare Google Business Profile (GBP)
- [ ] Competitor research (top 5 concurenți pe keywords principale)
- [ ] Identificare conversii disponibile (tel, form, chat, booking)

## Faza 1: Tracking Setup (zi 2-3)
- [ ] Creare/verificare cont GA4
- [ ] Instalare GTM
- [ ] Tag: GA4 Configuration
- [ ] Tag: Google Ads Conversion Tracking (telefon + form + WhatsApp)
- [ ] Tag: Enhanced Conversions (dacă e posibil)
- [ ] Verificare conversii în Test Mode
- [ ] LocalBusiness Schema Markup pe homepage + contact

## Faza 2: Keyword Research (zi 3-4)
- [ ] Export Google Keyword Planner pentru nișă
- [ ] Segmentare pe intent: High / Mid / Low
- [ ] Identificare negative keywords de la start
- [ ] Competitor keywords (SemRush/free tools)
- [ ] Final keyword list aprobată de client

## Faza 3: Campaign Build (zi 4-5)
- [ ] Creare structură campanie (1 campanie Search → N ad groups)
- [ ] Ad copy: min. 3 RSA per ad group (15 headlines, 4 descriptions)
- [ ] Extensions: Sitelinks, Callouts, Call, Location, Promotion
- [ ] Negative keyword list aplicată
- [ ] Bid strategy: Manual CPC (luna 1) → Target CPA (după 30+ conversii)
- [ ] Geo targeting setat
- [ ] Ad schedule setat (orele cu răspuns garantat)
- [ ] Review final înainte de lansare

## Faza 4: Launch & Monitor (săptămâna 1-2)
- [ ] Lansare campanie
- [ ] Check zilnic: impression share, CTR, CPC
- [ ] Check search terms report la 48h → negativi noi
- [ ] Verificare că conversiile se înregistrează corect
- [ ] Raport săptămânal client

## Faza 5: Optimizare lunară
- [ ] Search Terms Audit → negativi + noi keywords
- [ ] Headline performance → pause losers, adaugă noi
- [ ] Quality Score audit (sub 5 = problemă)
- [ ] Bid adjustments: device, location, timp
- [ ] Raport lunar complet (template `02 - Templates/Monthly Report Template.md`)
