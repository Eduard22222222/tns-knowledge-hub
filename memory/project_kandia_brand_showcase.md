**Update 2026-06-25b — REAL-PACKSHOT COMPOSITE (Eduard: "the rom packaging is not accurate").** Even with the real packshot as reference, nanobanana/Gemini renders the wrapper TEXT wrong ("LACTA"/"LATTO" instead of "LAPTE CU CREMĂ ROM", garbled "AUTENTIC") and Seedance re-imagines it again every frame → AI CANNOT produce an accurate branded pack in a video. **Deterministic fix = composite the REAL packshot pixels onto the bar, never let AI render the wrapper.** Pipeline that worked: (1) re-render the Seedance clip with a **LOCKED-OFF camera + STATIC bar/hand** motion prompt (only faces/hair/curtains move as they laugh) so the bar stays put across all 121 frames; (2) extract frames with ffmpeg; (3) **perspective-warp the real `rom_lapte.jpg` packshot onto the bar's 4-corner quad** using a numpy-computed PIL `Image.PERSPECTIVE` transform (no cv2 on this machine — `find_coeffs` solves the 8 coeffs via `np.linalg.solve`), with lighting integration (warm+dim, horizontal gradient since window light is camera-right, soft contact shadow, gaussian-blurred mask edges, +film grain) so it doesn't look like a sticker; (4) batch-composite ALL frames with the SAME static quad (bar was locked, drift negligible — verified first-vs-last align); (5) re-encode `ffmpeg -framerate 24 -crf 24 -pix_fmt yuv420p -movflags +faststart` → 1.2MB. Calibrate the quad by drawing it on a frame and iterating; **the bar tilts up-to-the-right** (red/left end LOW, blue/right end HIGH). NOTE Seedance output is 1920×1080 even from a 1376×768 start image → quad must be re-calibrated per resolution. **GENERAL TECHNIQUE for any accurate-product AI hero video: lock the product in the shot, then comp the real packshot per-frame — this is how real adverts do it too.** Accurate composited still saved as `_romref/rom_life_comp.png`.
